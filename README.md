# rock-paper-scissors
This is a rock-paper-scissors game played in the DevTools console--or, it was! 
I took the knowledge I've learned and applied it to make a UI for the game, complete with a scoreboard, updating message display (with a smooth scrolling effect) and an updating round counter.

I focused mainly on the UI design this time around, but I will experiment with different color schemes in the future (either here or on future projects) to bring my web pages to life.

Stay tuned for more projects!
